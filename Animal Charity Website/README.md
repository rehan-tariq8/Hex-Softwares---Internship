# 🐾 Animal Charity Website

A modern and responsive **Animal Charity Website** developed as part of my **Web Development Internship at Hex Softwares**. This project aims to raise awareness about animal welfare, showcase charity programs, encourage volunteer participation, and facilitate donations through an engaging and user-friendly web experience.

---

## 📌 Project Overview

The Animal Charity Website is designed to support animal rescue and welfare organizations by providing an online platform to share their mission, programs, donation campaigns, and volunteer opportunities.

The website features a clean and modern design inspired by professional charity fundraising platforms, ensuring an impactful and accessible experience for visitors.
