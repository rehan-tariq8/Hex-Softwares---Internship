## 📌 Project Overview

The **Glass Task Manager** is a modern and fully responsive To-Do Web Application developed using **HTML5, CSS3, Bootstrap 5, and JavaScript** during my internship at **Hex Softwares** as a **Frontend Developer Intern**.

This project helps users efficiently manage daily tasks with a clean and interactive interface inspired by modern **glassmorphism UI design**. The application allows users to add tasks, mark them as completed, delete tasks, and automatically store all tasks using the browser’s **localStorage**, ensuring data persistence even after page refresh.

The project focuses on creating a visually appealing user experience while implementing core JavaScript functionalities for dynamic task management.

# ⚙️ Functionalities Implemented

## ➤ Add Task

Users can enter a task in the input field and add it to the task list dynamically.

## ➤ Complete Task

Tasks can be marked as completed with a single click using the check button.

## ➤ Delete Task

Tasks can be removed permanently from the list.

## ➤ Local Storage Integration

All tasks are stored in the browser’s localStorage so they remain saved after refreshing or reopening the browser.
