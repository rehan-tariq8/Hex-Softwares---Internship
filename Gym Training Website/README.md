# Gym Training Website 🏋️‍♂️

A modern and responsive **Gym Training Website** developed as part of my **Web Development Internship at Hex Softwares**. The website is designed to promote fitness services, showcase gym facilities, highlight training programs, and present membership plans in an engaging single-page layout.

## 📌 Project Overview

This project focuses on creating a visually appealing and user-friendly fitness website using modern frontend development technologies. The design emphasizes strong branding, smooth navigation, and responsiveness across all devices.

## 🚀 Features

* Responsive single-page website design
* Modern hero section with call-to-action buttons
* Gym facilities showcase
* Personal training and fitness services section
* Membership plans and pricing cards
* Smooth scrolling navigation
* Interactive hover effects and animations
* Mobile-friendly layout
* Clean and professional UI/UX

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
