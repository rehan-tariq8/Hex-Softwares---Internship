# 🎵 Music Dashboard - Web Music Player

## 📌 Project Overview

Music Dashboard is a modern web-based music player developed as part of my **Web Developer Internship at Hex Softwares**. The application provides an interactive and visually appealing interface for playing music, managing playlists, controlling playback, and adjusting volume.

The project focuses on implementing core frontend development concepts using **HTML, CSS, and JavaScript** while delivering a smooth user experience and responsive design.

---

## 🚀 Features

### 🎼 Playlist Management

* Display a playlist containing multiple songs.
* Show song title, artist name, and duration.
* Scrollable playlist section for large song collections.
* Highlight the currently playing song.

### ▶️ Music Playback

* Play selected songs directly from the playlist.
* Pause and resume playback.
* Automatic transition to the next song when the current track ends.

### ⏮️ Playback Controls

* Previous Song button
* Play/Pause button
* Next Song button

### 📊 Progress Tracking

* Real-time song progress display.
* Current playback time indicator.
* Total song duration display.
* Seek functionality using the progress slider.

### 🔊 Volume Control

* Increase or decrease volume using a slider.
* Real-time audio volume adjustment.

### 🎨 Modern User Interface

* Dark-themed music dashboard.
* Dedicated playlist panel.
* Album cover display.
* Smooth animations and transitions.
* Highlight effect for the currently playing track.

### 📱 Responsive Design

* Optimized for desktop screens.
* Adaptive layout for tablets and smaller devices.

## ⚙️ Installation & Usage

### 1. Clone Repository

```bash
git clone https://github.com/your-username/music-dashboard.git
```

### 2. Open Project

Navigate to the project folder and open:

```text
index.html
```

in your preferred browser.

### 3. Add Your Own Music

Place audio files inside:

```text
Songs/
```

Place album covers inside:

```text
Images/
```

Then update the songs array in:

```javascript
script.js
```

with the correct file paths.
